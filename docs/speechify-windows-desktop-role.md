# Speechify Role Brief: Senior Software Engineer, Windows/Desktop Applications

## Mission
Speechify’s mission is to make sure reading is never a barrier to learning.

The product ecosystem includes iOS, Android, Mac, Chrome Extension, and Web App. The Windows/Desktop role is focused on building and improving native Windows experiences for a distributed product team.

## What You’d Do
- Lead design, architecture, and development of native Windows desktop applications.
- Work with Windows App SDK, WinUI, C#, XAML, and sometimes C++.
- Set and enforce best practices for architecture, performance, memory usage, responsiveness, compatibility, and maintainability.
- Drive accessibility work, including UI Automation, keyboard navigation, focus management, screen reader support, and inclusive UX.
- Collaborate with product design, UX research, QA, and other stakeholders.
- Own features end to end: design, implementation, testing, release, and maintenance.
- Investigate and fix bugs, performance bottlenecks, memory leaks, rendering issues, and compatibility problems.

## Required Background
- 3+ years in Windows desktop app development using Windows App SDK, WinUI, C#, and XAML.
- Strong understanding of managed/native interop.
- Experience shipping production desktop software with a focus on reliability and maintainability.
- Strong accessibility experience on Windows.
- Solid engineering fundamentals: OOP, design patterns, data structures, algorithms, memory management, and async/concurrency.
- Experience leading technical design, mentoring engineers, and making architecture decisions.
- Strong communication and collaboration skills.
- User-centric mindset.

## Preferred Experience
- Automated testing for desktop and UI surfaces.
- Performance optimization for startup time, memory, rendering, and responsiveness.
- Localization, globalization, RTL support, and internationalization.
- Telemetry, analytics, crash reporting, logging, and error monitoring.
- CI/CD workflows, release pipelines, and deployment strategies.
- Ownership of modules or feature areas, including refactoring and technical debt management.

## What the Role Emphasizes
- Architecture over patching.
- Accessibility as a first-class requirement.
- Performance and memory discipline.
- Cross-functional collaboration.
- End-to-end ownership.
- Strong product judgment for polished user experiences.

## How to Prepare
- Practice explaining tradeoffs clearly and concisely.
- Review Windows desktop architecture and UI accessibility patterns.
- Be ready to discuss performance investigation and debugging approaches.
- Prepare examples of refactoring, mentoring, and technical leadership.
- Have a clear story for how you ship stable, maintainable desktop software.
